## 第一板块 程序整体功能与代码模块说明

### 1.1 项目概述

本项目实现了一个基于真实天体物理模型的陨石撞击地球情景模拟系统。用户可自定义陨石的直径、材质、入射速度、入射角、撞击目标（陆地/海洋）、海洋深度、观测距离等参数，系统通过标准大气阻力—烧蚀理论（Chyba 1993 + ReVelle 1979）沿轨迹做数值积分，给出：大气烧蚀质量比、解体高度、空爆/地表撞击模式判定、冲击波三区半径、火球半径与三度烧伤半径、撞击坑直径、海啸浪高、五级灾害分级等完整物理仿真输出。前端使用原生 Canvas2D 渲染大气分层、陨石轨迹、爆炸粒子、冲击波环、撞击坑、城市距离标尺等可视化要素，并结合 132 条分类模板生成伪 AI 灾害推演文本（逐字打字机效果）。系统同时提供 **Flask 后端版**（Python 仿真 + API 驱动）与 **JS 独立版**（单文件 HTML，离线运行可转发）两种交付形态。

### 1.4 各核心代码模块功能

#### 1.4.1 常量模块 `physics/constants.py`（等价 JS：`part1_base.js`）

#### 1.4.2 陨石基本量模块 `physics/meteoroid.py`

负责最基础的几何与能量换算，**不做任何数值积分**。核心函数：

```python
def compute_mass(diameter_m, material_key):
    """球体质量：M = (4/3)π r³ ρ"""
    r = diameter_m / 2.0
    rho = MATERIALS[material_key]["density"]
    return (4/3) * math.pi * r**3 * rho

def compute_radius_from_mass(mass_kg, density):
    """烧蚀过程中由剩余质量反推瞬时半径"""
    return ((3*mass) / (4*math.pi*density)) ** (1/3)

def compute_kinetic_energy(mass_kg, velocity_kms):
    """动能：E = ½ M v²，注意 v 从 km/s 转 m/s"""
    return 0.5 * mass * (velocity*1000)**2
```

#### 1.4.3 大气密度模型 `physics/atmosphere.py`

实现 **带垂直梯度的多层指数大气近似**，相比单一标高模型在 25 km 以上误差降低约 40%：

```python
def air_density_with_gradient(h):
    if h < 25_000:
        return ρ₀ · exp(−h / 8500)       # 对流层 / 平流层
    ρ_25 = ρ₀ · exp(−25000 / 8500)
    return ρ_25 · exp(−(h−25000) / 6000)  # 中层大气衰减更慢
```

该分段模型直接决定陨石**何处开始有效减速、何处动压触发解体**，是 trajectory 积分器的输入基础。

#### 1.4.4 大气轨迹积分器 `physics/trajectory.py`（最核心模块）

欧拉法数值积分，步长 `dt=0.01 s`，每 50 步采样一次供前端动画使用。遵循 Chyba 1993 + ReVelle 1979 的完整控制方程组：

| 方程 | 变量 | 物理含义 |
|---|---|---|
| dv/dt = −(ρₐ v² C_D A)/(2m) − g·sinθ | 速度 v | 阻力加速度 + 重力切向分量 |
| dm/dt = −(ρₐ v³ C_H A) / Q_abl （仅 v>3 km/s）| 质量 m | 气动加热烧蚀，低速进入暗飞行阶段 |
| dh/dt = −v·sinθ | 高度 h | 向下为正 |
| dθ/dt ⇒ vₓ, vᵧ 分解 | 弹道倾角 θ | vₓ 仅阻力衰减；vᵧ 阻力 + 重力持续加速；合成倾角自动变陡 |
| q = ½ ρₐ v² ≥ σ ⇒ Pancake 触发 | 动压 q | 首次超过材料强度 σ 时 A 放大 PANCAKE_FACTOR 倍 |
| dE_dep = ½ ρₐ v³ C_D A · dt | 大气沉积能量 | **仅阻力做功功率**，不包含烧蚀质量带走的汽化内能 |

**三类能量严格分离**（对齐 NASA 撞击模拟器口径）：
- **初始总动能** E₀ = ½ m₀ v₀² （真空理论值）
- **大气沉积能量** E_atm = Σ dE_dep （阻力做功，驱动空爆冲击波 / 热辐射）
- **地面终端动能** E_gnd = ½ m_f v_f² （真实落地能量，决定撞击坑 / 海啸）

**地面终点插值**：当积分步跨越 h=0 时，按上一采样点与当前终态的线性比例求 frac，补采样至 h=0 精确对齐，避免前端动画爆炸点"悬空"。

#### 1.4.5 终态模式判定 `physics/breakup.py`

读取 `trajectory_result` 的 terminal 和 breakup 字段，三模式互斥判定：

1. **地表撞击**（`terminal.impact_happened = True`）
   - 解体后地撞：碎片云撞击 Pancake 放大后横截面积
   - 完整硬撞击：未触发解体，整块砸向地面
   - ground_efficiency = 1.0，释放能量 = 终端动能
2. **空爆（通古斯模式）**（`breakup.triggered = True` 且未触地）
   - ground_efficiency = 0.85（空爆杀伤效率高于地撞）
   - 释放能量沉积在解体高度附近
3. **大气烧毁**（两者均不成立，典型 <20m 小天体）
   - ground_efficiency = 0，地面无灾害

额外输出：穿透比 `penetration_ratio = (4/3 · r · ρ_body) / ATM_COLUMN_MASS`。当该比值 ≫ 1 时，天体必然穿透大气层；km 级天体穿透比通常 > 100，直观解释为什么必然地撞。

#### 1.4.6 撞击坑计算 `physics/crater.py`

采用 Collins et al. 2005 简化公式（垂直入射近似 θ=90°）：

```
D_t = 1.161 · (ρ_i / ρ_t)^(1/3) · d_m^0.78 · v_ms^0.44
D_final = 1.25 × D_t    （重力塌陷修正）
```

- 海洋目标 → 坑径强制 0，改走海啸模块
- 空爆 / 烧毁模式 → 坑径强制 0（无实体接触）

#### 1.4.7 冲击波破坏范围 `physics/shockwave.py`

Sachs 立方根缩放（核爆标准算法）：r = Z × W^(1/3)，W 为 TNT kg 当量，Z 为分区缩放距离：

| 分区 | 超压阈值 | Z 值 | 破坏描述 |
|---|---|---|---|
| 核心摧毁区 | 20 psi | 2.0 | 地面汽化、建筑完全消失 |
| 次级坍塌区 | 10 psi | 3.0 | 建筑全部坍塌、林木焚毁 |
| 外围玻璃碎裂区 | 1 psi | 8.0 | 窗户震碎、轻度损毁 |

#### 1.4.8 热辐射毁伤 `physics/thermal.py`

```
火球半径（经验）：r_fireball = 0.0023 × E^(1/3)
三度烧伤半径：   r_burn    = sqrt( E / (4π × 4.184×10⁵) )
```

E 单位均为 J，结果除以 1000 转 km。火球系数取自冷战核爆实测数据库。

#### 1.4.9 海洋海啸 `physics/tsunami.py`

海洋撞击经验公式：

```
H = 0.07 × sqrt(E) / d^(0.25)    (E 单位 J, d 单位 m, H 单位 m)
```

非海洋目标或释放能量为 0 时自动返回 0。注意该结果为**撞击点紧邻海区浪高估算**，对海岸衰减未做建模。

#### 1.4.10 灾害分级 `physics/classify.py`

国际小行星撞击风险五级体系（按 **实际释放 TNT 吨当量** 定级）：

| 等级 | 直径阈值 | TNT 当量阈值 | 中文等级 | 典型后果 |
|---|---|---|---|---|
| L1 微型 | <20 m 或 <10³ t | <10⁶ t | 微型撞击 | 大气消耗，无地面损伤 |
| L2 小型 | <50 m 或 <10⁶ t | 10⁶ ≤ E < 10⁹ t | 小型灾害 | 局部城镇级损毁 |
| L3 中型 | <500 m 或 <10⁹ t | 10⁹ ≤ E < 10¹² t | 中型灾难 | 城市群毁灭性打击 |
| L4 大型 | <2000 m 或 <10¹² t | 10¹² ≤ E < 10¹⁵ t | 大型灾变 | 跨区域生态崩溃 |
| L5 灭绝级 | 其余 | ≥10¹⁵ t | 灭绝级撞击 | 全球气候扰动、生物圈大灭绝 |

observer_damage 同时给出观测距离所在的分区描述。

#### 1.4.11 编排器 `simulation.py`

串联上述 10 个模块，输出标准 `run_simulation(params)` 返回字典，顶层结构：

```python
{
  "input_echo":      {...用户参数回显},
  "initial":         {质量, 动能, TNT, 趣味对标},
  "trajectory":      {samples, terminal, breakup, ablation, energy_distribution},
  "mode":            {终态模式判定结果},
  "release":         {实际释放能量 J/TNT},
  "crater":          {撞击坑},
  "shockwave":       {冲击波三区},
  "thermal":         {火球+烧伤},
  "tsunami":         {海啸},
  "disaster_level":  {五级分级},
  "observer_damage": {观测点位置描述},
}
```

该字典即前后端通信的唯一契约，字段一旦固定不在运行时增删。

#### 1.4.12 数据采集与批量数据集生成 `dataset_generator.py`

并行化批量仿真引擎：
- 参数值域严格约束（直径 5~5000 m，75% 概率集中在 5~800 m；速度 12~70 km/s；角度 5~90°）
- 每条样本结构：`{sample_id, input, physics, user_query, ai_report}`
- `user_query` 从 4 套提问模板随机抽取并插值
- `ai_report` 基于 physics 字段动态模块化拼接（基础信息 → 烧蚀解体 → 冲击波 → 撞击坑/海啸 → 灾害等级）
- 输出 `impact_db_v3.json`（1000 条样本）用于主程序伪 AI 快速查找

#### 1.4.13 模板系统 `impact_templates_v1.json`

主键 = 能量等级 L1~L5 × impact_type(airburst/surface) × material(ice/rock/iron) × target(land/ocean) × angle_group(G1/G2/G3，仅 L2~L4)，共 132 条规则。每条模板包含 12 个插槽（`{{diameter}} {{velocity}} {{final_tnt}} {{remain_mass_ratio}} {{breakup_altitude}} {{fireball_r}} {{blast_core_r}} {{blast_outer_r}} {{burn_r}} {{crater_r}} {{tsunami_h}} {{angle}}`），填充后组合成完整推演文本。材质差异化文案硬性约束：ice 强调"结构疏松、能量分散"；iron 强调"致密坚固、集中地撞"。

#### 1.4.14 前端可视化渲染 `templates/index.html`

Canvas2D 原生绘制，所有元素坐标基于 `canvas.width / canvas.height` 相对计算，不写死像素值：

- **星空背景**：按画布尺寸均匀撒点，白蓝色散点随机
- **大气分层**：0~12km 对流层、12~50km 平流层、50~85km 中层、85~600km 热层、600km+ 外层，带卡片标注
- **陨石轨迹**：空间段直线，大气段二次 Bézier 曲线（控制点在入射方向延长线下方，避免"倒车"）
- **爆炸效果**：冲击波圆环（α 渐变扩散）+ 粒子飞溅 + 空气解体碎片轨迹
- **撞击坑**：纯黑色 #000000 下半圆，坑半径按 physics 输出×2（与灾害环比例尺一致）
- **城市标尺**：上海为原点，两侧等距展开 500 / 1000 / 2000 km，标签分上下排列避免重叠
- **拖拽与缩放**：鼠标左键拖拽旋转视角，滚轮连续缩放；近视图用平面投影，远视图映射到球面，过渡区间用 smoothstep 平滑插值
- **背面剔除**：球面模式下 crater 和标记点在球的背向半球不绘制

### 2.3 核心代码实现要点

#### 2.3.1 重力切向分量的加入（必做修复）

常见错误：只写阻力加速度 `a_drag = ρv²C_D A/(2m)`，忽略重力沿轨迹切向分量。低速段和低空段误差会累积到 15% 以上。

**正确做法**：将速度分解为 vₓ（水平）、vᵧ（向下为正）两个分量：

```
dvₓ = −a_drag · (vₓ/v) · dt
dvᵧ = (−a_drag · (vᵧ/v) + g) · dt    ← g 这一行就是重力切向分量
```

重力只作用于 vᵧ，使 vᵧ 在阻力抵消后仍有「额外下坠」，轨迹自然弯曲。

#### 2.3.2 弹道倾角动态演化

常见错误：θ 全程固定 = 入射角度。这会让陨石垂直方向永远以 sinθ 匀速下降，低速下水平速度衰减更快但 θ 不变导致弹道「抬头」反物理。

**正确做法**：每步 `v = sqrt(vₓ²+vᵧ²)`，然后 `θ = atan2(vᵧ, vₓ)`。vₓ 衰减快 → vᵧ 占比越来越大 → θ 持续变陡 → 弹道自然弯曲，符合真实火流星观测。

#### 2.3.3 大气能量沉积算法（最容易错的公式）

**错误算法**（网上 80% 开源实现都错在这里）：
```python
e_dep = ½m₁v₁² − ½m₂v₂²   # 用"动能差"直接当大气能量
```
这个算法把烧蚀带走的质量携带的自身动能也计入了大气冲击波，严重虚高（对 100 m 冰彗星偏差可达 40%~60%）。

**正确算法**（学术标准）：
```python
e_dep = ½·ρₐ·v³·C_D·A · dt   # 仅阻力做功功率 × dt
```
烧蚀质量的消耗转化为汽化内能（Q_abl = 5×10⁶ J/kg），**不计入冲击波能量池**。两者严格分离，这才与 NASA 模拟器口径一致。

#### 2.3.4 Pancake 模型单次触发

用 `breakup_triggered` 布尔标志位。一旦 q ≥ σ 触发一次，pancake_mult 从 1 → 5，后续循环不再重复判定。否则会出现"第二次解体"的非物理行为，能量出现断崖二次异常沉积。

#### 2.3.5 速度下限保护

每步 `v = max(v, 0.0)`。浮点误差下 v 可能略微变负 → 平方变正 → 阻力反向推物体 → 能量发散正反馈。必须强制钳制。

#### 2.3.6 暗飞行阶段（烧蚀截止）

仅当 `v > 3000 m/s` 时调用烧蚀公式。陨石减速到 3 km/s 以下气动加热不足以维持汽化，进入"暗飞行"。否则小质量陨石会持续烧蚀到 0 以下，出现负质量。

#### 2.3.7 地面终点插值

欧拉法默认 dt=0.01s，大天体末速度 10~20 km/s，每步跨越 100~200 米。若直接在 h<0 时截断，会出现：陨石末帧画在 h=-150m 地下，坑体浮起。做法：

```
frac = h_last / (h_last − h_cross)   # 跨越地面比例
t_ground = t_last + (t_curr−t_last) · frac
v_ground = v_last + (v_curr−v_last) · frac
m_ground = m_last + (m_curr−m_last) · frac
# 再补 1 个采样点到 h=0
```

#### 2.3.8 三类能量分离

在 trajectory 返回结构中显式给出 `energy_distribution` 字典，包含：
- `initial_kinetic_j`：真空理论总能量
- `atmospheric_j`：阻力沉积到大气（空爆/冲击波/热辐射池）
- `ground_impact_j`：终端落地（撞击坑/海啸池）
- 对应两个 `*_ratio`

前端的 energy_comparison / narrative / disaster 报告从这三个字段取数，避免口径混乱。

#### 2.3.9 打字机伪 AI 效果（前端）

逐字 setTimeout 推进，基础速度 35 ms/字。遇到 `。！？；，、\n` 等字符时暂停 150 ms，模拟 AI 「思考停顿」；段落结束光标用 `▋` 闪烁动画。纯前端可实现，不依赖 DeepSeek。

#### 2.3.10 独立版打包要点

### 2.4 功能调试方法

#### 2.4.1 数值稳定性调试（白盒）

在 trajectory.integrate_trajectory 的每个采样点追加 `console.log / print`：
- m ≥ m₀（除非烧蚀）→ 断言 `Math.abs(m_prev − m_curr) / m_prev < 0.02`
