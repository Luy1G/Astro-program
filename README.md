# 陨石撞击模拟器（Astro-program）

输入一颗陨石的大小、速度、材质和角度，30 秒内看到它撞上地球的全过程：会在空中爆炸还是砸到地面？坑有多大？冲击波能传多远？对观测点造成什么破坏？——全部由物理公式实时算出，并自动对照历史上真实发生的陨石事件。

## 为什么要做这个项目

2013 年车里雅宾斯克陨石空中爆炸，约 1500 人受伤——陨石撞击不是科幻话题，而是真实存在的自然风险。但"直径 60 米、速度 19 公里每秒"这些数字对公众非常抽象。本项目把撞击过程变成**可交互、可计算**的可视化模拟，让抽象的天文风险变得看得懂、算得出。

## 30 秒体验

**最简单的方式（无需安装任何东西）：** 双击打开 [`陨石/JAVA版html.html`](陨石/JAVA版html.html) → 选择材质和参数 → 点击「▶ 运行模拟」→ 观看撞击全程动画与灾害报告。

**Web 完整版（需 Python）：**

```bash
cd 陨石/final/v3.0
pip install flask
python appV2.0.py        # 浏览器打开 http://127.0.0.1:5003
```

**建议演示的三组参数：**

| 演示场景 | 材质 | 直径 | 速度 | 看点 |
|----------|------|------|------|------|
| 通古斯事件复现 | 岩石陨石 | 60 米 | 27 km/s | 低空爆炸（空爆），对照 1908 年真实事件 |

| 大型撞击 | 岩石陨石 | 1000 米 | 20 km/s | 地面撞击坑 + 大范围灾害等级 |

## 它是怎么算的（不是动画特效，是物理计算）

模拟器不是播放预设动画，而是从物理定律出发逐步计算：

1. **大气进入**：计算陨体在大气中的减速、加热与烧蚀
2. **碎裂判定**：根据动压判断陨体是否解体、在什么高度空爆
3. **能量释放**：计算撞击/空爆动能（TNT 当量），对照广岛原子弹、地震震级
4. **灾害推演**：撞击坑直径（沙坑标度律）、冲击波超压、热辐射灼烧半径
5. **事件对照**：在内置的 132 条真实历史陨石事件库（通古斯、车里雅宾斯克等）中自动匹配"同类事件"

主要参数输出包括：空爆高度、撞击坑直径、L1–L5 灾害等级、各距离观测点的破坏效果。理论依据与计算公式详见 [《核心科学理论依据》](陨石/Aug10/陨石撞击模拟｜核心科学理论依据（程序计算底层原理）.md)。

## 项目特色

- **真计算，非演示**：全部灾害数据由 Python 物理模块逐步积分计算，修改任意参数都能得到自洽的新结果
- **物理引擎模块化**：大气、碎裂、撞击坑、冲击波、热辐射等 9 个独立模块（`physics/` 目录），结构清晰可扩展
- **真实事件库支撑**：132 条历史事件模板自动匹配，结果有史实参照而非凭空估计
- **双形态发布**：Flask 网页版 + 零依赖单文件离线版，无网络也能完整运行
- **AI 辅助交互**：支持用自然语言提问（"一颗 100 米铁陨石撞海洋会怎样"），由本地规则引擎解析并联动仿真
