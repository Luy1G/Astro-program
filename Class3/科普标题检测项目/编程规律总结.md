# 编程规律发现总结

## 项目概述

本次项目实现了一个科普网站标题爬取与标题党检测系统，包含爬虫模块和分析模块。

## 爬虫模块规律

### 1. 网页请求规律
- 使用 `requests.get()` 发送HTTP请求时，添加 `User-Agent` 头可以提高请求成功率
- 设置 `timeout` 参数防止请求无限等待
- 使用 `response.apparent_encoding` 自动检测编码，避免中文乱码

### 2. HTML解析规律
- 使用 BeautifulSoup 的 `find_all()` 方法定位元素
- `get_text(strip=True)` 可以去除文本前后的空白字符
- 通过 `href=True` 条件筛选带链接的元素

### 3. 数据去重规律
- 使用 `set()` 集合去重，避免重复提取相同URL
- 在列表添加前检查元素是否已存在

## 分析模块规律

### 1. 标题党关键词规律
通过检测，发现标题党常用以下几类词汇：

| 类型 | 关键词示例 |
|------|-----------|
| 情绪夸大 | 震惊、可怕、恐怖、致命 |
| 强制性引导 | 必看、别再被骗、涨知识 |
| 绝对化表述 | 99%、彻底、完全 |
| 情感煽动 | 爆哭、绝了、破防、泪目 |
| 热度炒作 | 上热搜、全网、刷爆 |

### 2. 标题党特征规律
- 标题党通常使用夸张、情绪化的语言
- 常包含数字（特别是百分比）来吸引注意力
- 往往使用强制性动词（必看、别再...）

## 模块化设计规律

### 1. 单一职责原则
每个模块专注于单一功能：
- `WebCrawler`：只负责网页请求和数据提取
- `TitleAnalyzer`：只负责标题分析和判断

### 2. 信息隐藏原则
- 内部实现细节对外部不可见
- 通过公开方法提供受控访问

### 3. 代码复用规律
- 将共用的配置（如请求头、关键词库）集中管理
- 避免代码重复，提高可维护性

## 运行结果规律

从中国科普网爬取的113个标题中：
- 正常标题：112条 (99.12%)
- 疑似标题党：1条 (0.88%)

**发现**：正规科普网站的标题党比例极低，说明科普网站内容质量较高。

2. 引入机器学习算法提高检测准确率
3. 支持更多网站格式的解析
