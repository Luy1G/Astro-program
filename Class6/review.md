# 项目复盘总结：ArXiv 论文科普文章生成器

## 一、项目概述

### 1.1 项目背景
本项目旨在构建一个自动化的学术论文科普文章生成系统，核心目标是：
- 从 arXiv 网站爬取最新论文
- 利用 DeepSeek API 智能分析并选择最具科普价值的论文
- 将学术论文转化为面向大众的科普文章
- 生成美观的 HTML 展示页面

### 1.2 项目时间线

### 2.2 核心组件

| 文件 | 功能 | 技术要点 |
|------|------|----------|
| `arxiv_crawler.py` | 爬取 arXiv 论文 | 使用官方 API，XML 解析 |
| `paper_selector.py` | 论文选择与 PDF 下载 | DeepSeek API 分析 |
| `pdf_parser.py` | PDF 解析与科普生成 | PyPDF2 + DeepSeek API |
| `html_generator.py` | Markdown 转 HTML | markdown 库 + 自定义模板 |
| `run_all.py` | 一键运行脚本 | 命令行调用封装 |

### 2.3 关键技术决策

1. **数据来源**：选择 arXiv 官方 API 而非网页爬取，稳定性更高
2. **大模型集成**：使用 DeepSeek API，响应速度快，中文支持好
3. **配置管理**：API Key 独立存储在 `config.env`，提高安全性
4. **提示词管理**：提示词存放在 `prompts/` 目录，便于维护和修改

## 三、实现过程

### 3.1 阶段一：爬取 arXiv 论文

**初始方案**：尝试解析 arXiv 网页 HTML

**遇到问题**：网页结构复杂，解析不稳定

**解决方案**：改用 arXiv 官方 API（`http://export.arxiv.org/api/query`），返回标准 XML 格式，解析更可靠

### 3.2 阶段二：论文选择与 PDF 下载

**关键功能**：
- 调用 DeepSeek API 分析论文摘要
- 根据趣味性和科普价值评分选择最佳论文
- 自动下载 PDF 文件到本地

**遇到问题**：PDF 文件名包含非法字符导致下载失败

**解决方案**：过滤 Windows 文件名非法字符（`\ / : * ? " < > |`）

### 3.3 阶段三：PDF 解析与科普文章生成

**关键功能**：
- 使用 PyPDF2 提取 PDF 文本内容
- 调用 DeepSeek API 将学术内容转化为科普文章
- 支持 Markdown 格式输出

**遇到问题**：部分 PDF 文件下载不完整导致解析失败

**解决方案**：选择文件大小合理的论文，确保下载完整

### 3.4 阶段四：HTML 生成与美化

**关键功能**：
- 使用 markdown 库将 Markdown 转为 HTML
- 自定义 CSS 样式，打造美观的阅读体验
- 支持响应式设计，适配不同屏幕

**遇到问题**：CSS 中的花括号与 Python format 冲突

**解决方案**：改用 f-string 字符串拼接

### 3.5 阶段五：内容优化

**关键功能**：
- 为科普文章添加相关图片
- 选择与内容匹配的科技主题图片

**遇到问题**：部分图片服务不稳定

**解决方案**：切换到 Unsplash 图片库，稳定性更高

### 6.1 技术选型
- **优先使用官方 API**：比网页爬取更稳定、更可靠
- **配置文件化**：敏感信息（如 API Key）应独立存储
- **错误处理**：网络请求和文件操作需要完善的异常处理

### 6.2 开发流程
- **分步测试**：每个模块独立测试通过后再集成
- **日志记录**：添加调试信息便于定位问题
- **代码复用**：相似功能抽取为函数，提高代码可维护性
